# AntigravityProxyLauncher v2.8.1 For macOS x86_64 / arm64

**发布日期**：2026-11-26
**上一发布版本**：v2.8.0-macos（2026-11-24）

本次发布聚焦一件事：**让客户端认知的上下文窗口与映射后的真实后端一致**。模型映射把请求送到本地或第三方模型后，客户端仍按 Gemini 官方窗口排布上下文，一路把 prompt 顶到后端上限才由上游报错拒绝——本次在模型映射规则上开放「上下文窗口 / 最大输出」，代理据此改写模型目录，让客户端按真实窗口压缩上下文。

## 🆕 新功能

### 模型映射支持声明上下文窗口与最大输出

- 模型映射规则的「映射目标模型」右侧新增两列：**上下文窗口**（`context_window`）与**最大输出**（`max_output_tokens`）
- 代理拦截 `v1internal:fetchAvailableModels`，把规则里声明的值写入对应源模型的 `maxTokens` / `maxOutputTokens`，客户端随即可按真实窗口排布上下文
- 未填写 = 完全不干预，响应体逐字节不变（有测试锁定该行为）
- `fetchAvailableModels` 有 12h 缓存，但改写发生在**每次返回时**，改配置后重启客户端即生效，无需等缓存过期
- 命中时会打一条日志，便于现场核对：

```
[Gemini] model window: claude-sonnet-5-5-medium -> maxTokens=128000 maxOutputTokens=8192
```

### 内置 Gemini 模型永不缩窗

- 规则目标服务商是内置 Gemini 时，两列输入框置灰并给出专门提示；代理侧同时硬性跳过
- 即使配置文件里被手工写了 `options`，也不会作用到内置 Gemini 设备模型上

### 两条安全告警

- 声明的窗口低于客户端固定压缩阈值（50000）时提示：压缩只能靠预算兜底路径触发
- `max_output_tokens ≥ context_window` 时提示：客户端会拒绝或截断

### 诊断：辅助 RPC 响应只读落盘

- `touch ~/.config/antigravity/dump_rpc` 后，`listExperiments` / `loadCodeAssist` / `fetchUserInfo` 等辅助 RPC 的响应体会写到 `~/.config/antigravity/rpc_dump/`，每 RPC 一个文件、覆盖写、不落 SSE 流、原样回传
- 默认关闭，标记文件不存在时零开销

## 🔍 关于压缩阈值：不动，且已排除服务端覆盖

本次没有改压缩逻辑，也没有引入任何阈值字段。压缩阈值仍是客户端内置 profile 表的值（12 条 profile + `claude-1m_840k` 变体，**13/13 全是 `50000`**）。

同时用上面的 RPC dump 做了一次只读取证，确认 **`v1internal:listExperiments` 等辅助 RPC 不下发 `token_threshold`，也不下发 `model_profiles`**；服务端唯一参与压缩配置的是 flag：

```
checkpoint-variant             = "claude-1m_840k"    # 只决定选哪条 profile
use-model-reported-token-count = true
max-tokens-per-step            = 16384
rules-token-budget             = 20000
```

结论：阈值没有服务端覆盖路径，`50000` 就是运行时真值。详见 `tools/mitm_proxy/CONTEXT_WINDOW.md`。

## 📊 实测效果

同一会话在改动前会被顶到后端上限并被拒绝：

```
this model's maximum context length is 262144 tokens, but the prompt contains 262676 input tokens
```

仅超 532 token，客户端毫无防守。为 Claude 规则声明 `128000 / 8192` 之后：

| 指标 | 改动前（11:54–13:11） | 改动后（13:29–14:06） |
| --- | --- | --- |
| 上游 4xx / 网关 502 | 25 条 | **0** |
| `context_length_exceeded` | 25 条 | **0** |
| 窗口改写生效 | — | 两次重启均生效 |

峰值 body 从 929 KB 降到 376 KB（约 112k tokens），常态 274 KB（约 81k tokens）。

## 💡 配置建议

- 声明值建议取**后端真实窗口的 75%–90%**，留出输出与摘要余量
- `< 50000`：压缩只能走预算兜底，上下文会偏晚压缩
- `> 后端真实窗口`：上游 4xx 或截断
- LLM Router 规则要取**所有关键字分支里的最小窗口**；分支窗口量级差距大时，建议拆成多条规则或不同源模型

## 📦 安装

- **DMG**（推荐）：挂载后把 App 拖到 Applications
- **ZIP**：解压后直接运行
- 未签名公证，首次打开如被拦截请右键「打开」，或 `xattr -dr com.apple.quarantine /Applications/AntigravityProxyLauncher.app`

## ⚠️ 已知限制

- 窗口改写只对**出现在 `fetchAvailableModels` 目录里**的模型生效
- 代理日志读不到精确的 `precompaction_token_count`（未开 `stream_options.include_usage`），需要精确数字时从客户端 `CompactionUsageMetadata` 侧观测
- `v1internal:fetchAdminControls` 在本次抓取中未被客户端调用，若其下发的模型清单优先级更高，可能覆盖目录窗口——当前未观测到该路径参与
