# AntigravityProxyLauncher v2.8.0 For macOS x86_64 / arm64

**发布日期**：2026-11-24
**上一发布版本**：v2.7.0-macos（2026-11-03）

本次发布聚焦三块：网关出口与稳定性（HTTP/HTTPS 上游代理、请求体上限、控制类 RPC 重试、gzip）、Launcher 生命周期治理（端口回收、配置热重启、系统代理探测），以及 Gemini 4 模型清单同步。

## 🆕 新功能

### 上游代理支持 HTTP / HTTPS

- 新增 `UPSTREAM_PROXY=type://host:port`，优先级高于旧 `SOCKS5_PROXY`、`proxy_config.json` 与默认 `127.0.0.1:7897`
- 修复：在 Launcher 里把代理类型选成 `http` 时，网关仍按 SOCKS5 拨号——日志显示配置成功，实际每个请求都直连并失败。现在 HTTP(S) 上游会正确建立 CONNECT 隧道
- 模型映射与纯透传两种启动模式共用同一出口配置，日志口径一致
- TLS 握手 10s→15s、响应头超时 60s→120s，弱网/远距离出口不再频繁误判超时

### Gemini 4 模型清单（按官方文档 + App v2.34.0 核对）

- 新增 **Gemini 4 Neon**（默认，low/medium/high/xhigh）、**Gemini 4 Carbon**（low/medium/high）、**Gemini 4 Hydrogen**（low/medium/high/xhigh），保留 Gemini 4 Argon
- Claude Opus / Sonnet 5.5 增加 `max` 档位
- 同步 WorkBuddy 网关模型清单，修正无效 ID
- Orchestrator（`gemini-pro-orchestrator`）为企业版复合模型，消费端不可直接调用，故不纳入内置清单

### CodeBuddy / WorkBuddy 模型清单（2026-11-24 同步）

按网关 `GET /v2/enterprises/personal/models` 的最新下发清单（与 WorkBuddy 模型选择器同源）同步，并用真实 stream 请求逐个验证：

- **新增**：Hy4（`hy4std`）、`hy4flash`、`hy4flash-free`（限时免费）、GLM-5.0、Kimi-K3（`kimi-k3-1`）、`auto`、`default`
- **移除**：`hy3`（当前账号 11158 无权限）、`hy4free`（11102 已下线），以及已不在目录内的 `hy3-b/c/x`、`hy4-preview-*`、`glm-5.3-flashx`、`kimi-k3-2`、`minimax-m3-pay/m2.7` 等旧别名（其中多数仍可用，已写入代码注释，需要时可在路由规则里手填）
- 目录内仍列但本账号返回 11102 的 `glm-4.6/4.6v/4.7`、`minimax-m2.5`、`kimi-k2-thinking`、`hunyuan-2.0-thinking`、`hy4-preview-x` 不收录
- 图片/视频类模型（`hunyuan-image-alpha`、`kling-video-v3`、`minimax-video-h3`）只能走多模态生成接口，`/v2/chat/completions` 不适用，不收录

### 提示词兼容模式（对外接口）

- 支持 OpenAI 新版 `developer` 角色：网关不接受该角色（即使内容中性也回 400 code 11128），占位消息统一降级为 `system`
- 合并开头连续的 `system`/`developer` 指令消息，避免后面那条原始提示词仍被指纹命中
- 仅在命中已知指纹（DeepSeek Harness / Claude Code）或请求出现 `developer` 时改写，普通请求保持原样

### Launcher

- 设置页新增「模型映射」总开关；provider 卡片新增「提示词兼容模式」开关
- 首次启动用 `scutil --proxy` 探测系统代理作为默认出口（跳过网关自身端口）
- `agy` CLI 包装器禁用自动更新（`AGY_CLI_DISABLE_AUTO_UPDATE=1`），签名权限丢失时自愈；健康检查新增「包装器被覆盖」「注入权限丢失」两项

## 🐛 修复

- 请求体 10MB 静默截断改为 100MB 上限 + 超限 413：截断产生的半截 JSON 会让上游回 400 `Closing quote expected in string`，排查方向完全跑偏
- 控制类 RPC（如 `fetchAvailableModels`）独立 32s 预算 + 一次超时重试；已取消的请求不再重试
- SSE 逐块 Flush，修复流式响应「憋到最后一次性吐」
- 大请求体 gzip 压缩；分段计时只在慢/大请求时打印，减少日志噪音
- 出口黑洞时快速失败；修正工具 schema 数值字段
- Launcher 崩溃后指数退避重启（2s→60s），主动退出不再误判为崩溃；启动前校验 18081 端口归属再回收
- 保存代理配置 / 切换模型映射后自动重启网关，避免进程仍拨号旧端口导致全部 502
- DMG 版式写入修复（挂载点目录名需与卷名一致）
- 内置 provider 新增模型自动并入已有配置

## 说明
